# VsKahlina

Mobile web **5-shot penalty shootout** vs Charlotte FC goalkeeper **Kristijan Kahlina**.

Virtua Striker / N64 low-poly arcade look with Bank of America Stadium–style bowl (upper blue seats, dark **CLT [crown] FC** fascia, suite windows, dual sky-blue LED ribbons with diegetic GOAL/SAVE/shot UI, concrete section numbers, denser lower crowd).

**Repo:** https://github.com/swiftsolves-msft/VsKahlina

## Play

1. Open `index.html` (needs `style.css`, `s0.js`…`s7.js`, `sboot.js`)
2. Tap **KICK OFF**
3. Flick / swipe the ball toward goal
4. Faster flick = more power
5. Kahlina reads early flick direction, then dives
6. 5 shots → GOAL / SAVE / MISS → rematch

Mute toggles SFX. Vibration on goal/save when available.

## Deploy

Static-host the folder. GitHub Pages on `main` → `https://swiftsolves-msft.github.io/VsKahlina/`
